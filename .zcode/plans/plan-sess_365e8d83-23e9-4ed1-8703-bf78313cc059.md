# Character Builder: Single Mode + Trimmed Spec + Saved Characters Reuse

**Branch:** worktree `.worktrees/feature/character-reuse` branched from current HEAD (`feature/story-continuation`). Install deps there (symlink or reinstall).

## Task 1 — Single mode + trimmed spec (lib/character.ts)

**Kill the dual-mode system.** Remove `CharacterMode`, the `mode` field, `ModePicker`, the landing's Normal/Uncensored cards, and `sanitizeSpecForMode`. The **global Uncensored Mode gate** (`userSettings.uncensoredEnabled` — same gate Solo/Story already use) becomes the single switch.

**Merge the option tables** into gated sets (`clothingGroups(uncensored)`, `accessoryGroups(uncensored)`, `expressionOptions(uncensored)`, `bodyDetailOptions(uncensored)`, `personalityTemplates(uncensored)` keep their signatures but return the merged table filtered by the gate):
- Outfits: everyday set (Casual, Formal, Sportswear, Uniform, Traditional, subcontinent safe set…) always visible; adult set (Lingerie, Underwear only, Nude, transparent/wet variants, subcontinent adult set…) only when the gate is on. Drop the redundant "Fully clothed" option (default is Casual).
- Expressions / body details / accessories / personality templates: merged union, adult entries gated.

**Trim the spec (33 → 22 fields).** Remove: `aspect`, `resolution`, `nudity`, `sexualContent`, `bodyType`, `height`, `weight`, `pose`, `violence`, `sceneNotes`, `mode`. Delete their tables (`BODY_TYPES`, `HEIGHTS`, `WEIGHTS`, `POSES_*`, `VIOLENCE_*`, `NUDITY`, `SEXUAL_CONTENT`, `SCENE_NOTE_TEMPLATES_*`) and helpers (`poseOptions`, `violenceOptions`, `sceneNoteTemplates`). Merge `bodyType` → `build`. Keep `nsfwLevel` (0–5 slider, forced to 0 when the gate is off — it's now the only adult-intensity control).

**Prompt composition restructure:**
- New `composeCharacterAnchor(spec)` — identity text extracted from today's composer ("portrait of an adult young adult woman, 18+, …").
- `composeCharacterPrompt(spec)` = base prompt + anchor (wizard render).
- New `composeSceneWithCharacter(scenePrompt, spec, uncensoredEnabled)` = sanitized anchor + scene prompt (reuse path; an adult character can never leak into a safe render).
- `characterGenerationSettings(spec, params: { aspect, resolution, modelId? }, uncensoredEnabled)` — safe/enhance/negativePrompt now follow the gate; aspect/resolution come from the caller.
- New `sanitizeSpec(spec, uncensoredEnabled)` replaces `sanitizeSpecForMode`: clamps selections to the gated lists, zeroes nsfwLevel and clears adult personality picks when the gate is off.
